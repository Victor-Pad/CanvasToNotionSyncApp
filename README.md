## Canvas to Notion Assignment Sync

A lightweight web app built with Python, Flask, and HTML/CSS that automates the process of fetching assignments from Canvas LMS and organizing them into Notion for improved productivity and task management.

### ✨ Features

- 🔗 Connects to Canvas API to fetch upcoming assignments.
- 📑 Syncs assignments into a Notion database via the Notion API.
- 🎯 Organizes assignments with due dates, course names, and statuses.
- 🌐 Simple Flask-based web interface for easy setup and sync control.
